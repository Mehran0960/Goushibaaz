# ثبت قابلیت منابع ویدئویی گوشی‌باز

آخرین بازبینی: ۱۷ نوامبر ۲۰۲۶

این سند میان چهار قابلیت مستقل تفاوت می‌گذارد: **کشف ویدئو، اندازه‌گیری تازگی/شتاب، دسترسی مجاز به فایل، و حق بازنشر در فیلو**. هیچ منبعی صرفاً به‌دلیل عمومی بودن، آمار زیاد یا قابل دانلود بودن، مجاز به انتشار خودکار نیست.

## منابع فعال و سطح دسترسی

| منبع | کشف و تازگی/شتاب | فایل و حق بازنشر | مسیر فعلی |
|---|---|---|---|
| فیدها و دسته‌های فیلو | اسکن چرخشی دسته‌ها؛ تاریخ انتشار و شمارنده‌های پخش/بازدید؛ سه نمونهٔ مستقل و رشد اخیر | مجوز بومی باید در جزئیات هر ویدئو صریحاً فعال باشد؛ صدا، امکان درآمدزایی، فعال‌بودن و وضعیت انتشار نیز کنترل می‌شوند | **انتشار خودکار فعال** با گیت age-adaptive و تأیید URL عمومی |
| Telegram | ۲۷ کانال پایه و کشف پویای کانال‌های جدید از فهرست‌ها؛ شمارنده‌ها/تغییرات قابل مشاهده در چند snapshot | لینک یا فایل قابل مشاهده، مجوز بازنشر ایجاد نمی‌کند | **کشف و سیگنال موضوعی**؛ بدون دانلود خودکار محتوای دیگران |
| Aparat | حدود ۶۰ جست‌وجوی موضوعی فارسی و سنجش snapshotهای تکراری | «بازنش» بومی آپارات، فایل قابل انتقال به فیلو نیست؛ لینک عمومی مجوز دانلود نیست | **کشف و سنجش تقاضا** |
| YouTube / Shorts | جست‌وجوهای فارسی و تصویری؛ دادهٔ عمومی و فیلتر Creative Commons در حد متادیتای قابل دسترسی | API فایل MP4 تحویل نمی‌دهد؛ برچسب CC به‌تنهایی مجوز استفاده از downloader غیررسمی یا تضمین حقوق تمام اجزای ویدئو نیست | **کشف و سنجش تقاضا**؛ انتقال فقط با فایل/مجوز قابل احراز |
| Wikimedia Commons | جست‌وجوی چندین ده عبارت موضوعی و اتصال به snapshot ترند | فایل و مجوز هر آیتم باید مستقل بررسی شود؛ فقط مجوزهای پذیرفته‌شدهٔ policy | **انتشار خودکار مشروط** به حقوق، فایل، صدا، مدت و کیفیت |
| Internet Archive | جست‌وجوی چندین عبارت و فیلتر نتایج دارای فایل و مجوز قابل تشخیص | مجوز آیتمی و شرایط همان صفحه/فایل ملاک است؛ عنوان کلی مجموعه به‌تنهایی کافی نیست | **انتشار خودکار مشروط** به تمام گیت‌ها |
| Pexels | API برای کشف متادیتا و پیشنهاد موضوع | شرایط فعلی Pexels کپی‌برداری انبوه/گسترده/سیستماتیک را بدون اجازهٔ صریح ممنوع می‌کند؛ مجوز عمومی محتوا این محدودیت را حذف نمی‌کند | **فقط discovery**؛ ingest خودکار با default-off و نیازمند تأیید مکتوب |
| Pixabay | در Registry برای ارزیابی آینده نگهداری می‌شود | مستندات API کش ۲۴ساعته را الزامی و درخواست‌های خودکار زیاد/دانلود سیستماتیک را منع می‌کند | فعلاً به چرخهٔ ۱۵دقیقه‌ای وصل نیست |
| Coverr، Mixkit و سایر کتابخانه‌ها | تا زمان ارزیابی adapter و دسترسی پایدار، منبع فعال شمارش نمی‌شوند | API، licence، محدودیت bulk و اجازهٔ بازنشر باید برای هر سرویس جداگانه تأیید شود | فعلاً discovery/ingest خودکار فعال نیست |

## منطق انتخاب ویدئوی قابل انتشار

1. تازگی و رشد واقعی خود ویدئو مهم‌تر از تعداد تجمعی بازدید است. شمارندهٔ پخش اولویت دارد؛ بازدید فقط وقتی جایگزین می‌شود که شمارندهٔ پخش در دسترس نباشد یا برای سه نمونهٔ مستقل صفر و ثابت مانده باشد.
2. حداقل سه نمونهٔ مستقل لازم است. کشف هیچ cutoff ثابت سنی ندارد، اما آستانهٔ انتشار با سن تغییر می‌کند:
   - تا ۲۴ ساعت: حداقل ۰٫۰۵ شمارنده در دقیقه؛
   - ۲۴ تا ۷۲ ساعت: حداقل ۰٫۰۸ شمارنده در دقیقه و شتاب مثبت؛
   - بیش از ۷۲ ساعت یا سن نامعلوم: حداقل ۰٫۱۲ شمارنده در دقیقه و شتاب مثبت.
3. مومنتوم موضوعی چندمنبعه فقط سیگنال انتخاب است، نه جانشین رشد واقعی و نه مجوز بازنشر.
4. نامزدهای فاقد مجوز یا فایل مجاز در گزارش discovery حفظ می‌شوند، اما وارد صف دانلود/انتشار نمی‌شوند.
5. اگر هیچ نامزد از تمام گیت‌ها عبور نکرد، عدم انتشار نتیجهٔ صحیح است؛ انتشار اجباری برای حفظ تعداد ممنوع است.

## فعال‌سازی Pexels

متغیر مخزن `PEXELS_AUTOMATED_REPUBLISH_APPROVED` به‌طور پیش‌فرض `false` است. فقط پس از دریافت تأیید صریح و مکتوب Pexels دربارهٔ استفادهٔ سیستماتیک در این گردش‌کار، می‌توان آن را به `true` تغییر داد. گیت در اسکریپت دانلود نیز مستقل از workflow اعمال می‌شود؛ حذف متغیر workflow به‌تنهایی امکان دور زدن آن را نمی‌دهد.
