# دفتر تغییرات بازنشر بومی فیلو

## 2026-11-06 — امتیازدهی تقاضای موضوعی/مدت و مهار سقف بازنشر حساب

- محدوده: رتبه‌بندی ناشر بومی فیلو، تشخیص سقف حساب، تست‌های رگرسیون و مستندات.
- رتبه‌بندی جدید: ۷۶٪ رشد/شتاب واقعی، ۱۴٪ تقاضای هم‌گروهی در فیدهای جاری فیلو، ۸٪ ترجیح نرم مدت کوتاه و ۲٪ تازگی؛ ترتیب شواهد حفظ شد: رشد پخش، رشد بازدید، شمار تجمعی و fallback تازگی.
- تقاضای موضوعی از شمار نامزدهای متمایز در feed tag/دسته و سهم/میانگین رشد نامزدهای همان گروه محاسبه می‌شود؛ گروه تک‌نامزدی سیگنال تقاضای معتبر نمی‌سازد. این شاخص فقط تقاضای مشاهده‌شده در خود فیلو است.
- ترجیح مدت به‌صورت پلکانی است؛ ویدئوهای بالای ۱۸۰ ثانیه یا حتی بیش از ۶۰۰ ثانیه حذف نمی‌شوند. حداقل ۱۰ ثانیه و گیت نهایی فیلو حفظ شدند.
- خطای صریح «سقف بازنشر حساب تمام شده» دیگر به‌عنوان ۴۰۳ مختص یک نامزد cache نمی‌شود؛ یک cooldown سراسری ۲ ساعته ثبت می‌کند. طی آن کشف تازه و نمونه‌برداری رشد ادامه دارد، اما درخواست‌های جزئیات/ارسال بی‌فایده تکرار نمی‌شوند. پس از پایان، استعلام معتبر فیلو دوباره انجام می‌شود.
- شواهد انگیزهٔ اصلاح: Run #42195918003 در `2026-11-06T09:33:12Z` تعداد ۸۶۰ مورد را اسکن کرد؛ ۷۷۰ واجد پیش‌فیلتر بودند، اما بررسی جزئیات با خطای حساب «سقف بازنشر شما تموم شده؛ ساعاتی بعد برای بازنشر مراجعه کن» مواجه شد. چرخهٔ قبلی #42195278858 نیز ۲۹ مورد بررسی جزئیات با ۴۰۳ و همین پیام ثبت کرده بود؛ در آن چرخه فقط ۴ مورد از ۱٬۰۷۹ آیتم فید `can_republish=true` گزارش شده بود.
- گیت‌های مجوز صاحب اثر، وضعیت فعال/قابل‌انتشار، صدا، درآمدزایی، محتوای ممنوع، idempotency و بررسی مجدد جزئیات بلافاصله پیش از ارسال تغییر نکردند.
- تست‌های جدید برای وزن/رتبه‌بندی موضوعی، ترجیح نرم مدت، نبود سقف محلی و cooldown سراسری اضافه شدند؛ نتیجهٔ CI پس از اجرای PR ثبت خواهد شد.


این دفتر append-only است. برای هر تغییر کد، تست، workflow، زمان‌بندی، سیاست، دادهٔ تشخیصی، ساختار state یا اقدام عملیاتی غیرروتین مرتبط با بازنشر بومی فیلو، یک ورودی تاریخ‌دار اضافه شود. اصلاح ورودی‌های قبلی فقط برای تصحیح مستند و با توضیح روشن مجاز است.
